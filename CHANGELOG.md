# Changelog

All playable builds of Skybound: Riftkeeper. Each numbered drop is a full game, not a patch note dump.

## 0.5.0 — Dual Jump (2026-09-20)

Current version.

- Double jump works from Hookhaven. Tap jump on the ground, tap again in the air.
- Jump is a tap, not a hold. Hold still floats on the way down.
- Wrench (J / left click / Wrench) is always melee.
- Blaster (F / K / right click / Blast) always fires the equipped gun.
- 1–8, Tab, mouse wheel, and the Cycle button actually switch weapons.
- HUD shows Omniwrench · J and Pulse Blaster · F instead of a pile of identical icons.
- Title screen prints the version so builds can be told apart.
