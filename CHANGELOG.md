# Changelog

All playable builds of Skybound: Riftkeeper. Each numbered drop is a full game, not a patch note dump.

## 1.0.0 — Gate Closed (2026-09-20)

Current version. Same 3D campaign as the live game.

- Ten-world third-person campaign, double jump from Hookhaven, wrench + gun split
- Mobile HUD: score, bolts, lives, and Nix sit at the top so stick/buttons no longer cover them
- Landscape phones use the same top chrome (no more score sitting on Jump)
- Windows pack is this same 3D game (double-click Skybound.exe)
- Android APK is this same 3D game

## 0.5.0 — Dual Jump (2026-09-20)

- Double jump works from Hookhaven. Tap jump on the ground, tap again in the air.
- Wrench (J / left click / Wrench) is always melee.
- Blaster (F / K / right click / Blast) always fires the equipped gun.

## 0.4.0 — Ten Worlds

Browser 3D campaign. Rook Vane + Nix. Ten gates, gate meter, mobile stick.

## 0.3.0 — First 3D port

Python Dallas Skybound 2 rewritten in the browser.

## 0.2.0 — Python original

`Dallas_Skybound2` 2D pygame build uploaded by the captain.
