# skybound-riftkeepers

A game you love to play.

**Dallas: Skybound** is an original Mario-style side-scrolling platformer written in Python. You play a scarf-wearing explorer across three worlds: Sunlit Meadow, Twilight Works, and Aurora Ridge. Art and sound are generated by the source. No external game assets are required.

This repository is [dbrush95/skybound-riftkeepers](https://github.com/dbrush95/skybound-riftkeepers).

## Play

Requires Python 3.10+ and a desktop keyboard.

**Windows:** double-click `PLAY_WINDOWS.bat`. The first run creates a local `.venv` and installs Pygame (needs internet once).

**Windows / macOS / Linux:**

```sh
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
python game.py
```

Headless check:

```sh
python game.py --test
```

### Controls

| Action | Key |
| --- | --- |
| Move | A / D or arrows |
| Jump | Space, W, or up |
| Sprint | Shift |
| Start / next / retry | Enter |
| Pause | P or Escape |
| Sound | M |
| Quit | Q |

Jump on robots to defeat them. Hit gold **?** blocks from below. Reach the gold flag in each world.

## Versions

The Desktop folder had two snapshots. Their Python zips are identical; v0.2 also shipped a Windows installer.

| Folder | What it is |
| --- | --- |
| [v0.1/](v0.1/) | `Dallas_Skybound1.zip` plus extracted source |
| [v0.2/](v0.2/) | `Dallas_Skybound2.zip` plus extracted source. Windows installer: `Skybound_Riftkeepers_Setup2.exe` (~37 MB) |

Current playable files (`game.py`, `requirements.txt`, `PLAY_WINDOWS.bat`) are the extracted snapshot at the repo root.

The Windows installer is a large binary. If it is not in this repo, add it from your Desktop folder `Skybound riftkeepers/skybound-riftkeepers v.02/` as a [GitHub Release](https://github.com/dbrush95/skybound-riftkeepers/releases) asset.
