# Skybound: Riftkeeper v0.5.0 — Dual Jump

This is the **current** browser 3D campaign. Source of truth is the repo root `src/` folder.

## What 0.5.0 fixed

- Double jump from Hookhaven. Tap jump, tap again in the air.
- Wrench (J) is always melee. Blaster (F) always fires the gun.
- 1–8, Tab, mouse wheel, and Cycle actually switch gadgets.
- Title screen shows `v0.5.0` so this drop is not confused with 0.4 or the Python games.

See root `CHANGELOG.md` and `VERSIONS.md`.
